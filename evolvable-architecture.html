可进化架构 · 总览

整站鸟瞰见 总览 · 三问导读。本站「可进化」指：外部可观测线索能经可重复管道进入站内核（manifest、配方与沙盘），并由分析与沉淀反馈是否漂移——全程保留人审闸门，不是自动预言机。本页把各模块收束为一张架构图；工程分期与 WBS 见 整体改造，模型分层见 智能进化。

观测 — 双轨与抓取 编码 — manifest 与沙盘 反哺 — §11 · 沉淀 · 可选智能
定义与边界 七层闭环 结构示意 机制与产物对照 §11 插槽映射 推荐阅读顺序

1. 定义与边界

  • 可进化：信号从进入候选到升格为正式库，再驱动热力/沉淀/趋势，最后回到 综合推演 §11 与 沙盘——形成可审计闭环。
  • 不可自动化：未经审阅的 merge、直接改 HTML 正文、把热搜等同「国家意志」。
  • 与「架构拓扑」页区别：架构拓扑偏技术栈图示；本页偏站点如何随观测迭代。

2. 七层闭环（逻辑顺序）

  1. 语境与双轨：战略·舆情 把国家叙事与舆论场对齐十年窗。
  2. 观测与抓取：ingest → evolution-candidates.json（待审）；命令见 scripts/README.md（make ingest 与 make analyze 已拆分）。
  3. 编码与入库：人审后 merge → evolution-manifest.json；映射 pages / lab_factors。
  4. 读者侧同步：evolution.js 渲染信号栏；沙盘 高亮因子。
  5. 分析引擎：analysis_engine.py → analysis-snapshot.json（热力、共现、规则提示）。
  6. 记忆与趋势：--sediment → JSON + data/evolution.db；sediment_trends.py → 跨日持久度。
  7. 反哺与迭代：按提示修订 §6/§7/§11；可选 智能层 仅产出候选/工单。节奏模板：双周运行手册。
