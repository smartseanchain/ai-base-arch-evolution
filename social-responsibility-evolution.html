社会责任 · 可进化推演

整站鸟瞰见 总览 · 三问导读。本页将整体架构明确为可向社会责任取向进化：把社会舆情、政府文件与征求意见、国家战略与规划文本、商业舆情与行业议程等多源信号接入同一套观测—编码—分析—反哺管道，经自动聚合与规则提示驱动沙盘与 综合推演 §11 迭代——输出的是可检验的推演线索与组合压测，不是替代研读的自动结论。 与 战略·舆情 双轨、可进化架构 总览、智能进化 分层对齐。

1. 社会责任模型（在本站中的含义）

不是企业 CSR 报告模板，而是推演时显式纳入：公共利益、代际与弱势群体、环境与资源约束、劳工与平台议价、合规与可逆性——与 §2 判据、十年之问 中的「不要做什么 / 活得比较好」同构。架构向社会责任进化 = 信号路由更覆盖这些维度，分析热力能提示长期偏斜（例如监管+AI、算力+碳 共现持续走高）。

  • 国家战略/规划：与 十年展望·国家治理、职业·基建·能源 对表。
  • 政府文件与立法线索：映射 kind: policy | law，对接 立体联结、教育/关基叙事。
  • 社会舆情：议程与问责，映射 opinion，与战略轨对时差，见 双轨。
  • 商业舆情：行业、品牌、供应链、ESG 争议，映射 market 或与 opinion 并存，对接 网·商·资·工、地缘与商业。

3. 自动分析进化（本站已实现与可扩展）

  1. 抓取与路由：ingest_opinion_law.py 按配置写入 evolution-candidates.json。
  2. 人审入库：merge 至 evolution-manifest.json（站内核）。
  3. 自动分析：analysis_engine.py → 模块/因子热力、共现、规则提示；--sediment 沉淀 JSON + SQLite。
  4. 长期结构：sediment_trends.py 观察 Top 持久度。
  5. 可选智能层：摘要、映射建议、RAG（见 智能进化），默认进候选/工单，不自动改正文。
持续更新：一键 bash scripts/run_update_pipeline.sh；定时见 分析引擎 · §6。

4. 推演输出形态（「给出推演」指什么）

在不宣称预测的前提下，系统自动侧可稳定产出下列推演辅助，供人在 综合推演 与 沙盘 上完成判断：

  • 结构提示：哪些模块页、哪些 lab_factors 在多源信号中持续占优——对应「下一步应读哪几页、沙盘先勾哪几项」。
  • 共现与传导提示：规则 evolution_hints 与 分析引擎 仪表盘中的文字建议，指向 §6 配方或 §7 表行审阅。
  • 双轨对账：将新信号与 战略·舆情 中「文件—预算—议程」是否同步对照，避免单轨叙事。
  • 配方级产出：由人根据提示在 §11 下增删配方/表行；机器不直接写定稿段落。

5. 闸门与合规

来源：遵守 robots.txt 与版权；法规以权威发布文本为准，ingest 仅作线索聚合。

社会责任取向放大了对误读舆情的敏感度：热点≠公共利益；自动热力只反映「站内映射上的计数」，须经 §2 判据 与人工审阅再升格为站内核叙事。
