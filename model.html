分层与模型

整站鸟瞰见 总览 · 三问导读。左侧为责任切分（三平面），中间为技术纵深（L1–L6），下方为社会技术叠加（十层）与平面—议题条形图。

推演扩展 · 本轮更新（分层模型）

本轮三平面+L 层旁各加责任可命名性：故障时哪层出现在对外公告；与 配方 E/F、继续推演矩阵 对读。

  • 十层栈与七层模块表冲突时，以可对账合同与 SLA 为准。
  • 策略即代码叙事须接 拓扑 变更管道，防纸面策略。
  • 与 历史演进 并读：哪层词汇来自哪波投资记忆。
  • 平面—议题条形图每次更新问「是否改变中小企业固定成本假设」。

全景标签

未来基础架构更接近社会技术系统：身份、数据目录、策略与可观测连接分散算力与数据。

IDC / 边缘 多云 / 混合云 零信任 / SASE 数据主权 AI 基础设施 地缘 / 关基

三平面（控制 / 数据 / 安全）

评审时三平面需同版本对齐。

控制面

  • IAM、策略引擎、CIAM
  • GitOps、配额、服务注册
  • IaC、网格策略、路由意图
  • KMS、PKI 生命周期

数据面

  • OLTP / 对象 / 流 / 湖仓
  • API、CDC、队列
  • 分级驻留、备份拓扑
  • 向量库、RAG、推理流量

安全面

  • 零信任、mTLS、微分段
  • 日志、追踪、不可变审计
  • DLP、加密、令牌化
  • 镜像签名、SBOM、模型溯源

十层叠加栈

自下而上展开；上层压力向下传导。

1物理与能源
  • PUE、绿电、液冷、选址
  • 地缘下区域级失效考量
2算力与网络
  • 异构算力、SASE、mTLS
  • IPv6 / 遥测 / eBPF
3数据与身份
  • 分级分类、血缘、BYOK
  • SPIFFE、权限生命周期
4应用、API 与 AI
  • API 网关、Schema、限流
  • RAG 权限、模型供应链
5合规与主权
  • 数据地图、跨境、行业特规
  • 子处理者链条
6地缘与国家安全
  • 制裁、关基、供应链可信
  • Exit 路径、持续运营
7资本与治理
  • 融资合规债、董事会披露
  • M&A 尽调、主体与数据落点
8商业化与生态
  • 效率 / 风险 / 战略 价值
  • 认证、渠道、责任边界
9组织与运营
  • 平台 / SRE / 安全 / 合规
  • 非技术依赖图
10个人与声誉
  • T 型 + 合规翻译
  • 职业风险敞口
