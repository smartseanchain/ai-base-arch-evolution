          键盘快捷方式

          本页键盘快捷方式一览
          键或区域 说明
          / 视当前模块：在观测且焦点不在探索器正文时，聚焦片段筛选；否则聚焦数据源筛选（不在其他输入内时）。
          ? 或 Shift+/ 开关本表。打开时标签标题会临时带上「键盘快捷方式」，关闭后恢复。
          Esc 关闭本表；若在数据源或片段筛选框内，则清空筛选。
          顶栏 主题、快捷键说明、复制链接、刷新数据。复制链接带当前模块锚点；同步锚点时保留路径与查询参数。带 #mod-… 打开时，首屏与首次数据拉取后会对齐该模块。
          一键上手 概览里「一键拉取并检查」= 顶栏「刷新数据」；进行中均显示「拉取中…」。适合交接或第一次自检。
          模块顶栏（中等以下视口） 宽约 ≤60rem 时，七枚模块链接单行横向滑览（overflow-x: auto）；深链 #mod-… 时正文区有 :target 高亮。
          模块边界（读屏） 各模块 h2.module-title 用 aria-describedby 绑到导语（module-lead）和本组不做（module-boundary），读屏可一次听到能做与不能做。
          长页滚动 「跳到主内容」滚动并把焦点放到 #admin-main（tabindex=-1）。页脚也可开快捷键表；右下有「回到顶部」。
          动效与透明度 若系统偏好 prefers-reduced-motion 或 prefers-reduced-transparency，顶栏毛玻璃与平滑滚动会减弱或关掉，程序化滚动改为瞬时（与脚本里 prefersReducedMotionOrTransparency 一致）。
          系统配色 forced-colors 高对比时顶栏跟系统色。深浅色会写 theme-color；「跟随系统」用 matchMedia('(prefers-color-scheme: …)') 热更新。多标签改外观会通过 storage 同步。
          网络 上/下线会语音提示（读屏可听）。观测下方提示区有可读名称。
          观测 / 值守 「观测摘要」可自动刷新、选间隔、复制观测摘要；详情见上方读屏说明（含页签隐藏时暂停定时器）。
          并行刷新 支持 AbortSignal.timeout 时，/api/bootstrap、ingest-config（若已配只读基址）及并行 GET（/health、身份、历史、快照）每路约 60s，与探索器单请求一致。
          探索器正文 状态行报 HTTP、体积、耗时；读屏为 role=status + aria-live=polite。复制 / 再拉在旁侧工具条。正文可 Tab 聚焦滚动。
          复制摘要 「复制观测摘要」含标题、顶栏模块、稳定时的探索器状态行（无「请求中」等过渡句）、来源与路径；信号区用单一 aria-live 块播报，避免抢读。
          观测（快照与历史） 历史旁可复制说明；复制摘要会带上历史说明、探索路径、快照失败说明（若有）。
          当前快照 拉取失败时，错误说明旁有复制按钮，便于工单。
