          ? 或 Shift+/ 打开 / 关闭本说明
          Esc 关闭本说明；在数据源 / 片段筛选框内则清空筛选
          顶栏 右侧工具条含快捷键说明、复制链接与刷新数据；「复制链接」复制含当前模块锚点的完整 URL；随滚动同步锚点时保留路径与查询参数。打开 #mod-… 直达某模块时，首屏与首次数据拉取后会自动对齐该锚点。
          长页滚动 右下角「回到顶部」；主内容区支持 tabindex 便于键盘聚焦
          网络 浏览器在线 / 离线变化时，会通过页面内语音提示（读屏可听）。观测卡片下方提示列表有可访问名称，便于在文档结构中定位。
          观测 / 值守 「观测摘要」可自动刷新与间隔选择（读屏可通过「自动刷新」旁说明获知：成功时不播报语音提示、失败仍播报、页签隐藏时暂停）；另可复制观测摘要。值守与复制在同一工具条内。
          并行刷新 支持 AbortSignal.timeout 的浏览器中，/api/bootstrap、ingest-config（若已配只读基址）与并行 GET（/health、身份、历史、快照）各路约 60s 超时，与下方探索器单请求策略一致。
          探索器正文 状态栏含 HTTP 状态、字节数与请求耗时，并对读屏以 role=status / aria-live=polite 播报更新；复制与再拉取在独立工具条内，与状态行并列。正文可 Tab 聚焦便于键盘滚动
          复制摘要 「复制观测摘要」含页面标题与顶栏当前模块文案；在探索器有稳定状态时会附带状态行（HTTP / 体积 / 耗时等），不含「请求中」「随页面刷新」等过渡文案；有拉取记录时还可带来源标签与路径。观测卡片中信号列表以单一读屏播报区（aria-live）整体更新，避免多行各自抢占播报。
          分析与历史 「快照历史」旁可复制说明；「复制观测摘要」会附带历史说明、当前探索路径（若有）及快照拉取失败时的说明（若有）。
          当前快照 拉取失败时，错误说明旁有复制按钮，便于贴到工单或本地记录。
