1. 依据：我们默认的「当前形态」锚点

以下不引用虚构统计数字；列的是已广泛存在、可交叉验证的现象与制度类型，作为全站讨论的地面。

技术形态：移动终端与家庭宽带普及；企业工作负载大量运行于公有云、专有区域或托管 IDC；容器与 API 成为集成主通道；生成式 AI 以 SaaS、专有部署或混合方式进入工作流。
制度形态：主要经济体均已形成「个人信息/数据保护 + 行业监管 + 关键基础设施/网络安全」多层规则并存局面；数据出境、重要数据、关基保护等概念已进入企业法务与架构评审语言。
威胁形态：勒索软件、供应链攻击、凭证窃取与社工在公开安全报告中长期占据前列；国家级行为体对关键设施与供应链的影响已成为公共讨论与政策回应对象。
扩展说明：本站其余页面的「十年」「廿年」「沙盘」均建立在上述地面之上，讨论的是结构张力往哪边走，而非断言单一数值结局。

2. 立体尺度：个人 → 家庭 → 组织 → 国家（嵌套施压）

越往上层，变更越慢、杠杆越大；越往下层，体感越强、选择看似「私人」却受上层默认配置约束。立体体现在：同一人在多层同时扮演角色（公民、雇员、家庭成员）。

国家 / 法域 / 全球治理
立法、执法、出口管制、关基认定、产业政策、应急与战时逻辑。塑造：数据能否出境、哪些采购合法、关键服务连续性责任边界。
组织与市场
雇主、学校、医院、平台企业、云与 SaaS 供应商。塑造：默认用哪朵云、终端管控策略、日志与监控范围、AI 使用政策。
家庭与社区
家庭网络、共享设备、家长控制、社区数字化服务、小型商户 POS/收银云。塑造：儿童与老人数字暴露面、家庭存储与摄像头数据落点、本地宽带与 DNS 选择。
个人终端与身份
手机、笔电、可穿戴、多账户与生物特征。既是攻击入口也是合规「同意」的点击者；个体选择汇聚成平台与国家的可观测行为数据。

本节自检：能否用「个人—家庭—组织—国家」说明一个你关心的议题至少落在哪两层、谁在施压？

3. 分面：同一议题的五张「切片」（融合阅读）

基础设施讨论常被误读为「纯技术」；五面同时打开才能解释为何某架构在某一国可行、在另一国昂贵。

技术面

云、网络、身份、数据栈、AI 推理与训练拓扑；可观测性与自动化。

法律与监管面

个人信息、重要数据、出境、关基、行业特规、合同管辖与子处理者链条。

经济与市场面

FinOps、资本开支与 OpEx、云定价、人才成本、保险与合规采购。

安全与韧性面

勒索、供应链、业务连续性、红队与演练；国家级风险与日常企业风险的叠加。

家庭与社会文化面

数字鸿沟、代际信任、对监控与便利的取舍、对「国家云」「外国 App」的民间叙事——反压政策与产品设计。
融合示例：「儿童上网保护」同时牵动——路由器与家长控制（家庭）、教育 SaaS 与实名（组织）、未成年人立法（国家）、应用商店地域策略（市场）——缺一维则方案失真。

本节自检：对你当前议题，五面里哪两面最不可缺？缺哪一面会误读成「纯技术」或「纯政策」？

5. 互相影响的反馈环（简图 + 说明）

  • 国家 → 家庭：默认加密标准、内容治理、宽带基建、教育数字化政策改变家庭设备与应用的「出厂设定」。
  • 组织 → 个人：MDM、零信任、数据防泄漏决定个人在工作设备上的自由度和被观测粒度。
  • 家庭 → 国家：集体投诉、选举议题、生育与养老数字化诉求推动立法与补贴方向。
  • 个人 → 市场：工具与模型采用曲线倒逼云与 SaaS 路线图；安全事件舆情影响监管节奏。

本节自检：能否复述环上至少一条「自下而上」或「自上而下」反馈，并对应到个人或国家侧？

6. 想象：三种「融合强度」情景（明确为假设）

情景 A（低融合）：国家、组织、家庭数字策略脱节——企业用全球统一栈，家庭用消费级弱安全设备，监管执法滞后；总成本转嫁给个人与小商户。
情景 B（中融合，较常见叙事）：关基与重点行业强对齐，消费侧通过平台责任与标准逐步拉齐底线；Cell 与数据地图在 B 端先成熟，再向公共部门与家庭服务渗透。
情景 C（高融合）：数字身份、医疗与教育数据在强审计下跨域协作增多——依赖 TEE/联邦等技术与极强的制度信任；若信任崩塌则回退为情景 A。此为进取想象，非现状断言。

本节自检：能否指出 A/B/C 中哪几句是假设情景、哪几句是对当前地面的描述？
