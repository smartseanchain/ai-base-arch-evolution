# 枢纽分区 · 本页主问题（写作备忘）

<a id="hub-main-questions"></a>

与顶栏 **五组分区** 对齐：新增长页或改版枢纽时，在 **`page-head`** 的 **`read-hint.page-head-deck`**（或等价导读块）**首段**用 **`p.page-main-question`** 写明**本页独占的主问题**，便于读者扫读与 [SITE_REVIEW · §3.5](./SITE_REVIEW_THREE_PASSES.md#section-3-5-lead-readhint) 复查；版式类仍只按 [INTELLIGENCE · §2.2](./INTELLIGENCE_SIX_DOMAINS.md#reader-layout-contract)。**`h1` → `p.lead` →（五簇可选 `p.muted.hub-cluster-thread`）→ `read-hint`** 顺序见 [AGENTS · 枢纽首屏](../AGENTS.md#agents-hub-lead)；**`index.html`** 在 **`lead`** 后插 **`#index-intent-pick`** 四条动线卡再进 **`read-hint`**，与 [README · 产品视角](../README.md#pm-four-journeys) 对表。若页内有 **`nav.toc.toc--pilot`**（主目录，非「延展阅读」附块），在 **`toc-pilot-eyebrow`** 后**首链**加 **`#<stem>-main-question`** 文案 **「本页主问题」**，与 **`index.html`** 同构。长页若另有**中段** pilot（如 **`analysis-hub.html`** 在 **`#panorama`** 前的「本节速达」），同样在 eyebrow 后首链加 **「本页主问题」**，便于深读时跳回 **`page-head`**。特重枢纽（如 **`nexus` / `synthesis` / `analysis-hub`**，以及 **`lab` / `evolution-loop` / `decade` / `modules-map` / `evolution-triad` / `edu-nexus` / `decade-scenes`** 等长读页）可在各大 **`h2` 节末**用 **`p.muted.note-caption-82.section-readback`** 写一句 **「本节自检」**（读者能否回答一个具体问题），样式见 **`assets/site.css`** · **`.section-readback`**。

| 顶栏分区 | 本页主问题（一句，可贴入 `page-main-question`） |
|----------|--------------------------------------------------|
| **联结与模型** | 多尺度事实与制度如何叠成可讨论的「立体联结」，而不是单线技术故事？ |
| **时间与情景** | 在选定时间窗里，哪些情景假设改变了约束，哪些仍应视为常量？ |
| **推演与沙盘** | 给定判据与矩阵，本轮组合与分叉如何**可对账**，而不是一次性断言？ |
| **制度与地缘** | 制度、地缘与商业张力如何映射到架构与组织决策，而非口号化立场？ |
| **架构与分析** | 观测、契约与闸门如何支撑演进节奏，而不替代人对 manifest 的判断？ |

**总览（`index.html`）**：**角色从哪进**见 **`#index-intent-pick`**（与 [README · #pm-four-journeys](../README.md#pm-four-journeys) 同骨架）；**本页要答的主问题**见 **`#index-main-question`**，并与 [README · 从这里开始](../README.md#readme-start-here) 的读者完成标准对读。
