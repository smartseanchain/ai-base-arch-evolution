11. 持续梳理、扩展与推演：本页如何「不断生长」

读后自问：本轮循环卡在梳理、扩展还是推演？哪一条插槽该动？

梳理不是一次性读完 §1，而是每次把新现象对回变量表与判据；扩展是在不破坏可对账性的前提下加模块、加域、加配方、加表行；推演是强制产出传导链与至少一枝分叉（甲/乙/丙或 §8 簇），避免只有形容词。

若要做全站级一轮梳理（三问 → 模块图谱 → 本页判据/配方 → 分析读数 → 沙盘 → 决定改 JSON 还是改正文），见仓库 docs/SITE_WIDE_RERUN_DEDUCTION_PLAYBOOK.md，与双周 EVOLUTION_RUNBOOK 可同次或分次进行。

  • 扩展插槽 ①：新行业或新城市场景 → 在 §1 为对应页补「变量注」并标注所属系与堆叠位，同步 模块图谱 · 分系总表；再试能否落入 §2 某条判据。
  • 扩展插槽 ②：新传导命题 → 在 §6.2 按现有卡片结构增配方一条（模块链接 + 合理性 + 链 + 甲/乙/丙）。
  • 扩展插槽 ③：新复合矛盾 → 在 §7 表增一行（焦点 + 模块组合 + 趋势向量 + 形态词）。
  • 扩展插槽 ④：新可见征候 → 在 §9 增一小格，与五维或 9.x 系列并列，保持「可观察」而非口号。
  • 扩展插槽 ⑤：叠乘域再延伸—§6.2 已至 I—V（含 Q—V）与 §7 对应表行；下一轮若仍落不进现有字母，自增配方须含合理性+传导链+甲/乙/丙并指回 §2，必要时用 §12 固定方法外衣以免散文化。
  • 扩展插槽 ⑥：国家层面规划/试点节奏与舆论场不同步时 → 用 战略·舆情 把「文件—预算—招标」与「议程—问责」拆成两轨，再指回 十年展望·国家治理与 立体联结 的尺度嵌套，避免单轨叙事。
  • 扩展插槽 ⑦：外部信号（舆情、政策、法规标题、市场）持续涌现 → 先由 scripts/ingest_opinion_law.py 汇总为 assets/evolution-candidates.json，人审后再 merge_candidates_to_manifest.py 并入正式库；evolution.js 同时渲染已入库 + 候选并合并沙盘高亮；跑通一轮沙盘与 §7 对表后，再决定是否升格为 §6 配方 / §7 表行（忌自动 merge 无人审）。
  • 扩展插槽 ⑧：数据积累后运行 scripts/analysis_engine.py（可加 --sediment）→ 阅读 分析引擎 热力/共现与规则提示；若某模块页或因子长期占优，回到 §6/§7 做结构性补行或删陈旧叙事，形成「沉淀—分析—反哺」闭环。
  • 扩展插槽 ⑨：在 ⑦⑧ 之上引入模型与检索辅助（摘要、映射候选、RAG 带引用建议等）时 → 遵循 智能进化 的分层与闸门：产出默认进候选/工单，经 schema 校验与人审后再影响 manifest 或正文；忌未评测的「自动改站」。
  • 纪律：扩展若指不回 §2 任一条判据，降级为随笔，不进入表与配方；推演若无分叉，只能算摘要，不算完成一轮。
自我追问（每轮结尾用）：本轮是否把「电/钱/责任/时间」至少一个量纲说清？若只增加了形容词，回到梳理；若增加了新模块却无法对账，删掉或合并。

12. 跨学科推演办法：各研究领域的套路如何嵌进本站

读后自问：本轮只选一到两种手法时，你选哪两种？它们如何收紧 §2 判据而非堆术语？

下列不是「正确方法论」排名，而是可借用的思维外衣：把你在某一学科里习惯的推理步骤，显式对齐到 §1—§9 与 沙盘，避免只有术语没有可对账的链。一轮推演建议只主动选用一到两种，防止清单化表演。

升级导读：将认识论立场、三色证据分层、单轮七步流程、常见认知偏误及与 manifest / 分析引擎的审计对表收束为 docs/DEDUCTION_STRATEGY.md。各研究方法在本站「能用页面 / 能用脚本 / 仅能自建」的对照见 docs/RESEARCH_METHODS_MAP.md。与下表各行动态互补，而非重复。
领域或传统 常见手法（极简） 在本站中的落点 用时注意
战略与情景规划 关键不确定性 → 多情景树；反推里程碑与信号指标 §8 三簇、§5 每配方的甲/乙/丙、十年场景 三阶段色条 情景是叙事容器，仍需 §2「变量共享」才成立
技术预见 / 德尔菲类 结构化问卷、多轮意见聚合、分歧显式保留 适合团队年更时自建流程；本站不内置工具，产出应对回 §1 变量表 匿名轮次不能替代电/法域/合同等对账
系统动力学 / 控制论 反馈环、延迟、存量—流量；杠杆点辨析 §3 毗邻关系、各配方传导链里「谁放大/抵消谁」 定性环即可，不必强行上仿真软件
复杂适应系统（思想） 异质主体、局部规则、涌现形态 立体联结 尺度嵌套、家校政平台多方、§6 叠加域 涌现不是借口——仍要落到可见切片
因果推断（DAG、反事实） 混杂路径、识别策略、反事实对照 改配方一个前提看传导是否断链；拒绝把相关当因果——对齐 §2 本站不做估计量；只做逻辑可证伪叙述
历史与制度分析 路径依赖、临界事件、制度层叠 历史演进、廿年视角、时间维上的词汇与投资惯性 历史类比要写明机制对应哪一段链
工程可靠性（FTA / FMEA） 顶事件分解、严重度×发生度、单点失效 沙盘工坊 依赖流 SVG；§7 复合表中「谁先绷紧」 与治理/合同并读，避免纯技术树
运筹与敏感性分析 主因子、边界情景、龙卷风式排序 沙盘多因子勾选；对照 §7 行向量何者最先矛盾 排序依赖你已承认的前提，前提变则序变
政策过程 / 倡议联盟 联盟重组、叙事竟逐、政策窗口 十年展望·治理维、人与AI演进 分叉、地缘叙事 写明谁从现状获益，否则易空转
微观行为与离散选择（思想） 约束下选择、异质性偏好 十年之问 四问不同步、家庭「数字政治」 不拟合系数；只检查约束是否写漏
质性研究 / 民族志 厚描、可观察行为、情境合法性 §9 五维形态与各「可见切片」、配方卡片中的征候句 切片要能被别人在原则上复核
危机管理与红队 桌面推演、事前验尸、故意攻击叙事弱点 沙盘加压；§11 自我追问；与 地缘与商业 最坏情景并读 红队结论应增一行 §7 或一条配方分叉，不单是情绪

12.1 按「问题类型」选用（示意）

  • 谁先坏、何处单点：优先 FTA/FMEA 式分解 + 依赖流，再接到 §5/§6 传导链。
  • 为何同一国里体验分裂：复杂系统多方 + 制度层叠 + 四问不同步，用 §8 簇或 §5 分叉收束。
  • 是否漏了第三变量：因果图式追问 + §2 判据；必要时强制加读 职基能 或 拓扑 之一。
  • 叙事太乐观/太悲观：情景规划式写对立情景各一条可见征候；红队只攻击最脆的一环前提。
依据：上表各手法在各自学科中有更严格的操作定义；此处只取与定性传导链兼容的那一层，避免把本站冒充为计量模型或仿真平台。
扩展：若你所在领域还有可对接习惯（例如生态学的营养级联、法学的要件—效果链、医学伦理的利益冲突披露），可按 §11 扩展插槽 ① 自写一句「变量注」，仍须指回 §2 某条判据。
想象：同一议题连续三轮分别只用「情景树 / 反馈环 / 事前验尸」做主架——三轮结论若稳定重叠，可升格写入 §7；若三轮各说各话，说明 §1 变量表尚未对齐或前提冲突未写出。

13. 深读透镜：加深 · 多角度 · 多维度 · 多场景

读后自问：四穿透里哪一层你至今还指不出一条可对账变量？

本节不是新预测，而是阅读纪律：如何把已有页面当作可旋转的棱镜，让同一命题在技术、制度、市场与客厅之间多次显影，减少「单页读后过度自信」。

13.1 加深：四穿透（每层至少补一条可对账变量）

穿透层你在读什么典型入口加深检查句
① 实现与栈 哪一层命名、哪条链路承载 AI/数据/密钥；延迟与故障模式 分层模型、架构拓扑、沙盘 依赖流 能否指出具体层/Cell与计量单位（ms、kW、QPS）？
② 组织与契约 谁签字、谁运维、外包边界、岗位与技能包如何重写 人与AI演进、职基能·职业、配方 F/T 合同里默认承保方与 RTO是否与人事叙述一致？
③ 制度与叙事 细则、执法口径、产业与地缘话语如何改写采购与路线图 十年展望·治理/地域、地缘与商业、配方 A/H/Q/V 公文热搜词与一线可执行动作能否互译？
④ 客厅与身体 尊严、怕、时间与照护预算；代际与屏幕政治 立体联结、十年之问、配方 R/J 若政策落地，谁先失眠、谁先道歉能说清吗？

四穿透不必一次读完；但停在单层时，应在 §7 或笔记里标注「未穿透层」，以免把技术乐观当成社会结论。

13.3 多维度：四套「坐标」如何叠放（不混量纲）

  • 五系与七层：模块图谱 · 五系 定同窗互证范围；七层堆叠 检查是否缺 L1/L0 却在谈 L5—L6。
  • 时间维：历史演进 → 廿年视角 → 十年 六维阶段条 → 十年场景 三色条。问：同一技术在四张图里节拍是否一致。
  • 十年六维：架构 / 产业 / 职业 / 安全 / 治理 / 地域——先标出与你议题最相关的两维主矛盾，其余维当约束，避免六格同时喊最大声。
  • 合成三轴（本站 §4）：尺度 · 时间 · 硬栈——检查叙事是否落在「客厅最先痛」还是「机房最先痛」，以及硬栈是否 silent veto。
  • 形态五维 + 切片（§9）：把抽象簇落到可见征候；与 §8 三簇 对照，看同一家庭是否可能 β 而同一园区 α。

13.5 一趟「加深版」走法（可重复）

  1. 若需先建立全站鸟瞰，打开 模块图谱 的星丛/场景轮；再在 十年场景 选一个镜头，用 13.4 表圈定六维主读项。
  2. 走 13.1 四穿透各写一句：每层至少一个可对账名词（层、合同条款、kW、分钟、保单号等）。
  3. 用 13.2 六凝视者快速扫一遍：谁完全失声？→ 回 §1 补模块或 §2 判据。
  4. 把结论压进 §7 某行或 §6 某配方分叉，并用 §8 标簇（允许与家庭不同簇）。
  5. 进 沙盘 勾选与镜头相关的因子组合，对照 §12 任选一种方法外衣做第二轮。
  6. 收尾只保留三条可见征候 + 一条未决前提，写入 §11 下一轮迭代。
想象：同一周用三个不同镜头（如「算力能源」「家庭日常」「政务合规」）各跑一遍 13.5——若三条结论在电/钱/责任上指向同一绷紧顺序，该顺序可升格为个人或团队的主风险登记；若互相矛盾，优先修 13.1 未穿透层而非争论形容词。
